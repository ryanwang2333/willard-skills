# teach：跨会话带你学一个东西

当用户想**长期、跨多个会话**地学会某件事（而不是一次问答就结束）时，用本技能建立一套"教学工作区"，把学习变成有目标、有进度、可接续、可复习的过程。

## 建立教学工作区

把**当前工作目录**当作教学区（若当前没有可写的工作目录，先与用户确认一个可写的目录再开始）。教学区的状态用这些文件记录：

- `MISSION.md` — 教学目标：用户为什么想学、学会后能做什么。所有课程都围绕它；用户没想清楚时，第一件事是问清"为什么想学、想达到什么效果"。
- `lessons/` — 课程：每节课一个**自包含的 HTML 文件**，命名 `0001-<名字>.html`，只讲一件事、能快速看完；生成后以文件链接的方式交给用户打开。
- `reference/` — 参考资料（速查表、图解、代码片段），跨课程复用，供快速查阅。
- `learning-records/` — 学习记录：每次有阶段性成果就追加一条 `0001-<主题>.md`，记录"用户已经会了什么"，以后任何会话靠它接续。
- `NOTES.md` — 用户的学习偏好、常用术语、需要注意的点。

## 教法

- **每节课只讲一件事**：短小、马上能看完，并配一个用户随手就能试的小练习（反馈要即时、要具体）。
- 先教**知识**（优先从可信来源获取，不要凭记忆瞎讲），再让用户动手练**技能**，并结合**真实使用场景**。
- 目标是"**记得住**"而非"当时听懂"：新会话先快速回顾上节课，把练习分散到多次会话（间隔复习）。
- 用户提问时，**先给最简单的答案和例子，再逐步加深**，不要一次把复杂版本全倒出来。

## 维护

- 用户说"想学 X"且当前还没有教学区 → 先创建 `MISSION.md`，并问清楚动机和目标。
- 用户的偏好/术语写进 `NOTES.md`。
- 每次有进展 → 写一条 learning-record，让之后任何会话都能无缝接着教。
